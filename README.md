# IntelliDesk-AI-Productivity-Assistant-
IntelliDesk is an AI-powered productivity assistant developed using Python, JavaScript, HTML5, and CSS3. It integrates the OpenAI API to provide intelligent chat responses, text summarization, content rewriting, and study assistance through an interactive web interface. The application helps users save time, and manage everyday tasks efficiently.

**Features**

AI Chat Assistant

Text Summarization

Content Rewriting

Study Assistance

Smart AI Responses
**
Technologies Used**

Python

JavaScript

HTML5

CSS3

OpenAI API

REST API

**How to Run**

Download or clone the repository.

Open the project folder in VS Code.

Install the required Python packages.

Configure your OpenAI API key.

Run the application.
